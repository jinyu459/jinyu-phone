锦玉 APP 打包 · 操作步骤（纯文字版，不会有红红绿绿的标记）
================================================================

★ 先纠正一个大问题 ★
你刚才的命令是在 C:\Users\ASUS 这个"用户主目录"里执行的，
但你的项目其实在：
    C:\Users\ASUS\Desktop\jinyu-phone 3.0
所有打包命令都必须在这个【项目文件夹】里执行。
在 C:\Users\ASUS 里跑出来的 package.json 是跑到错地方了，
待会儿重新在项目文件夹里跑一遍就行（错的那个不影响，可留可删）。

----------------------------------------------------------------
第 1 步：把黑窗口"切"到项目文件夹
----------------------------------------------------------------
最简单的办法（强烈推荐，不用手打路径）：
  1. 打开桌面上的项目文件夹 jinyu-phone 3.0
  2. 点一下窗口顶部的"地址栏"，把里面的路径全部删掉
  3. 直接输入四个字母：cmd
  4. 按回车
  这时弹出的黑窗口，路径就已经在项目文件夹里了。

（如果不用上面办法，也可以在黑窗口里手打这行再回车）
    cd /d "C:\Users\ASUS\Desktop\jinyu-phone 3.0"

确认对不对：窗口里那行文字应该变成
    C:\Users\ASUS\Desktop\jinyu-phone 3.0>
看到这个就对了。

----------------------------------------------------------------
第 2 步：在项目文件夹里重新装一遍（一行一行复制，每行回车）
----------------------------------------------------------------
    npm init -y
    npm i @capacitor/core @capacitor/android
    npm i -D @capacitor/cli

说明：原来清单里的第 4 步 "npx cap init" 直接跳过（不用跑），
因为我们已经有 capacitor.config.json 了，再跑反而会覆盖它。

----------------------------------------------------------------
第 3 步：建 www 文件夹，把网页复制进去
----------------------------------------------------------------
（你现在的窗口是 CMD 命令提示符，就用下面这些 xcopy 写法，
  一行一行复制，每行按回车）

    mkdir www
    xcopy index.html www\ /Y
    xcopy admin.html www\ /Y
    xcopy auth.html www\ /Y
    xcopy apps www\apps\ /E /I /Y
    xcopy assets www\assets\ /E /I /Y

注意：不要复制这些进去：.docx 文档、patch_fix2.py、
      capacitor.config.json、初始化命令.md、这个纯文字文件。

----------------------------------------------------------------
第 4 步：生成安卓工程 + 同步
----------------------------------------------------------------
    npx cap add android
    npx cap sync android

第一次执行会联网下载一些东西，慢几分钟是正常的。

----------------------------------------------------------------
第 5 步：上传到 GitHub
----------------------------------------------------------------
先到 github.com 网页上新建一个【空的】仓库（什么都不要勾选），
然后在黑窗口里执行（把 <你的用户名>、<仓库名> 换成你自己的）：

    git init
    git add .
    git commit -m "init"
    git branch -M main
    git remote add origin https://github.com/<你的用户名>/<仓库名>.git
    git push -u origin main

----------------------------------------------------------------
第 6 步：云端自动打出 APK
----------------------------------------------------------------
打开你的 GitHub 仓库网页
  → 顶部点 Actions
  → 左边点 Build APK
  → 右边点 Run workflow，再点绿色按钮
  → 等 3~8 分钟
  → 点进这次运行，页面最下面 Artifacts 里下载 jinyu-phone-apk
  → 解压得到 app-debug.apk，传到手机安装

----------------------------------------------------------------
常见问题
----------------------------------------------------------------
· 命令提示"不是内部或外部命令"：去 nodejs.org 装 Node.js，
  装完把黑窗口关掉、重新开一个再试。
· 关于那个 .md 文件标红：那只是编辑器给 Markdown 格式上的颜色，
  不是报错，完全不用管。你只需要把里面的【命令】复制到黑窗口执行。
· 分不清 CMD 和 PowerShell：看窗口标题 / 提示符。
  提示符是  C:\Users\ASUS>  这种，就是 CMD，用 xcopy；
  若提示符前面有 "PS"，才是 PowerShell，用 Copy-Item。
